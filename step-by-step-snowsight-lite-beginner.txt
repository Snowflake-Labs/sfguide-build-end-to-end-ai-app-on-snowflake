Step-by-Step Instructions (Lite — Beginner, ~60 minutes)

Data to App in 8 steps. Everything runs from Snowsight + CoCo.
No git clone, no Python files, no external dependencies.

WHAT YOU'LL BUILD:
  - A database with 10M+ orders, 2M customers, 10 products
  - A 5-table Dynamic Tables pipeline (auto-refreshing)
  - Data quality monitoring with intentional gaps to discover
  - Cortex Search services over product catalog and customer feedback
  - A Semantic View for natural-language SQL
  - A Cortex Agent you can chat with in CoWork
  - A Streamlit dashboard — all from a CoCo prompt

PREREQUISITES
-------------
  [ ] ACCOUNTADMIN role access on your Snowflake account
  [ ] Cortex AI functions enabled (default on most accounts)
  [ ] Snowflake CoCo access via Snowsight Workspaces, CLI, or Desktop

-- Raw tables
CREATE OR REPLACE TABLE customers (
    customer_id INT PRIMARY KEY,
    first_name VARCHAR(50), last_name VARCHAR(50), email VARCHAR(100),
    phone VARCHAR(20), address VARCHAR(200), city VARCHAR(50),
    state VARCHAR(2), zip_code VARCHAR(10), registration_date DATE,
    customer_segment VARCHAR(20)
);

CREATE OR REPLACE TABLE orders (
    order_id VARCHAR(36) PRIMARY KEY,
    customer_id INT, order_date TIMESTAMP, order_status VARCHAR(20),
    total_amount DECIMAL(10,2), discount_percent DECIMAL(5,2), shipping_cost DECIMAL(8,2)
);

CREATE OR REPLACE TABLE order_items (
    order_item_id VARCHAR(36) PRIMARY KEY,
    order_id VARCHAR(36), product_id INT, product_name VARCHAR(100),
    product_category VARCHAR(50), quantity INT, unit_price DECIMAL(10,2),
    line_total DECIMAL(12,2)
);

CREATE TABLE IF NOT EXISTS product_catalog (
    product_id INT PRIMARY KEY, product_name VARCHAR(100), product_category VARCHAR(50),
    description TEXT, features TEXT, price DECIMAL(10,2), stock_quantity INT
);

CREATE TABLE IF NOT EXISTS product_reviews (
    review_id INT AUTOINCREMENT PRIMARY KEY,
    product_id INT, customer_id INT, review_date DATE, rating INT,
    review_title VARCHAR(200), review_text TEXT, verified_purchase BOOLEAN
);

CREATE TABLE IF NOT EXISTS support_tickets (
    ticket_id INT AUTOINCREMENT PRIMARY KEY,
    customer_id INT, ticket_date TIMESTAMP_NTZ, category VARCHAR(50),
    priority VARCHAR(20), subject VARCHAR(200), description TEXT,
    resolution TEXT, status VARCHAR(20)
);

-- Dynamic Tables pipeline (3 tiers)
USE SCHEMA dynamic_tables;

CREATE OR REPLACE DYNAMIC TABLE enriched_orders
TARGET_LAG = '1 minute' WAREHOUSE = hol_wh INITIALIZE = ON_SCHEDULE REFRESH_MODE = INCREMENTAL
AS
SELECT o.order_id, o.customer_id, o.order_date, o.order_status,
    DATE(o.order_date) AS order_date_only, YEAR(o.order_date) AS order_year,
    QUARTER(o.order_date) AS order_quarter, MONTH(o.order_date) AS order_month,
    DAYOFWEEK(o.order_date) AS order_day_of_week, DAYNAME(o.order_date) AS order_day_name,
    WEEK(o.order_date) AS order_week, o.total_amount, o.discount_percent, o.shipping_cost,
    ROUND(o.total_amount * (o.discount_percent / 100), 2) AS discount_amount,
    ROUND(o.total_amount - (o.total_amount * (o.discount_percent / 100)), 2) AS net_amount,
    ROUND(o.total_amount - (o.total_amount * (o.discount_percent / 100)) + o.shipping_cost, 2) AS final_amount,
    CASE WHEN o.discount_percent > 0 THEN TRUE ELSE FALSE END AS has_discount,
    CASE WHEN o.discount_percent = 0 THEN 'No Discount' WHEN o.discount_percent <= 10 THEN 'Low Discount'
         WHEN o.discount_percent <= 20 THEN 'Medium Discount' ELSE 'High Discount' END AS discount_tier,
    CASE WHEN o.total_amount < 100 THEN 'Small' WHEN o.total_amount < 500 THEN 'Medium'
         WHEN o.total_amount < 2000 THEN 'Large' ELSE 'Extra Large' END AS order_size_category
FROM dash_automated_intelligence_db.raw.orders o;

CREATE OR REPLACE DYNAMIC TABLE enriched_order_items
TARGET_LAG = '1 minute' WAREHOUSE = hol_wh INITIALIZE = ON_SCHEDULE REFRESH_MODE = INCREMENTAL
AS
SELECT oi.order_item_id, oi.order_id, oi.product_id, oi.product_name, oi.product_category,
    oi.quantity, oi.unit_price, oi.line_total,
    ROUND(oi.line_total / oi.quantity, 2) AS actual_unit_price,
    ROUND(oi.unit_price - (oi.line_total / oi.quantity), 2) AS unit_price_variance,
    CASE WHEN oi.product_category = 'Skis' THEN TRUE ELSE FALSE END AS is_skis,
    CASE WHEN oi.product_category = 'Snowboards' THEN TRUE ELSE FALSE END AS is_snowboards,
    CASE WHEN oi.quantity = 1 THEN 'Single' WHEN oi.quantity <= 3 THEN 'Few' ELSE 'Bulk' END AS quantity_tier
FROM dash_automated_intelligence_db.raw.order_items oi;

CREATE OR REPLACE DYNAMIC TABLE fact_orders
TARGET_LAG = DOWNSTREAM WAREHOUSE = hol_wh INITIALIZE = ON_SCHEDULE REFRESH_MODE = INCREMENTAL
AS
SELECT eo.order_id, eo.customer_id, eo.order_date, eo.order_date_only, eo.order_year,
    eo.order_quarter, eo.order_month, eo.order_day_of_week, eo.order_day_name, eo.order_week,
    eo.order_status, eo.total_amount, eo.discount_percent, eo.discount_amount, eo.net_amount,
    eo.shipping_cost, eo.final_amount, eo.has_discount, eo.discount_tier, eo.order_size_category,
    eoi.order_item_id, eoi.product_id, eoi.product_name, eoi.product_category, eoi.quantity,
    eoi.unit_price, eoi.line_total, eoi.actual_unit_price, eoi.unit_price_variance,
    eoi.is_skis, eoi.is_snowboards, eoi.quantity_tier,
    COUNT(eoi.order_item_id) OVER (PARTITION BY eo.order_id) AS items_per_order,
    SUM(eoi.line_total) OVER (PARTITION BY eo.order_id) AS order_items_total
FROM dash_automated_intelligence_db.dynamic_tables.enriched_orders eo
INNER JOIN dash_automated_intelligence_db.dynamic_tables.enriched_order_items eoi ON eo.order_id = eoi.order_id;

CREATE OR REPLACE DYNAMIC TABLE daily_business_metrics
TARGET_LAG = DOWNSTREAM WAREHOUSE = hol_wh INITIALIZE = ON_SCHEDULE REFRESH_MODE = INCREMENTAL
AS
SELECT order_date_only, order_year, order_quarter, order_month, order_week, order_day_name,
    COUNT(DISTINCT order_id) AS total_orders, COUNT(DISTINCT customer_id) AS unique_customers,
    AVG(items_per_order) AS avg_items_per_order, SUM(total_amount) AS total_revenue,
    SUM(net_amount) AS total_net_revenue, SUM(discount_amount) AS total_discounts,
    SUM(shipping_cost) AS total_shipping, SUM(final_amount) AS total_final_revenue,
    AVG(final_amount) AS avg_order_value,
    COUNT(DISTINCT CASE WHEN has_discount THEN order_id END) AS orders_with_discount,
    ROUND(COUNT(DISTINCT CASE WHEN has_discount THEN order_id END)::DECIMAL / COUNT(DISTINCT order_id) * 100, 2) AS discount_penetration_pct,
    AVG(CASE WHEN has_discount THEN discount_percent END) AS avg_discount_percent,
    COUNT(DISTINCT CASE WHEN order_size_category = 'Small' THEN order_id END) AS small_orders,
    COUNT(DISTINCT CASE WHEN order_size_category = 'Medium' THEN order_id END) AS medium_orders,
    COUNT(DISTINCT CASE WHEN order_size_category = 'Large' THEN order_id END) AS large_orders,
    COUNT(DISTINCT CASE WHEN order_size_category = 'Extra Large' THEN order_id END) AS extra_large_orders
FROM dash_automated_intelligence_db.dynamic_tables.fact_orders
GROUP BY order_date_only, order_year, order_quarter, order_month, order_week, order_day_name;

CREATE OR REPLACE DYNAMIC TABLE product_performance_metrics
TARGET_LAG = DOWNSTREAM WAREHOUSE = hol_wh INITIALIZE = ON_SCHEDULE REFRESH_MODE = INCREMENTAL
AS
SELECT product_category,
    COUNT(DISTINCT order_id) AS orders_count, COUNT(order_item_id) AS items_sold,
    SUM(quantity) AS total_quantity_sold, SUM(line_total) AS total_revenue,
    AVG(unit_price) AS avg_unit_price, AVG(quantity) AS avg_quantity_per_order,
    AVG(line_total) AS avg_line_total, MIN(unit_price) AS min_unit_price, MAX(unit_price) AS max_unit_price,
    SUM(CASE WHEN is_skis THEN 1 ELSE 0 END) AS ski_items,
    SUM(CASE WHEN is_snowboards THEN 1 ELSE 0 END) AS snowboard_items,
    COUNT(CASE WHEN quantity_tier = 'Single' THEN 1 END) AS single_item_orders,
    COUNT(CASE WHEN quantity_tier = 'Few' THEN 1 END) AS few_item_orders,
    COUNT(CASE WHEN quantity_tier = 'Bulk' THEN 1 END) AS bulk_orders
FROM dash_automated_intelligence_db.dynamic_tables.fact_orders
GROUP BY product_category;

-- Cortex Search Services

CREATE OR REPLACE CORTEX SEARCH SERVICE product_search_service
  ON description
  ATTRIBUTES product_id, product_name, product_category, features, price
  WAREHOUSE = hol_wh TARGET_LAG = '1 hour'
  AS (SELECT product_id, product_name, product_category, description, features, price, stock_quantity FROM product_catalog);

CREATE OR REPLACE VIEW customer_feedback AS
SELECT CAST(review_id AS VARCHAR) AS doc_id, review_title AS title, review_text AS content,
    'review' AS source_type, CAST(NULL AS VARCHAR(50)) AS category, rating, review_date AS date_field, customer_id
FROM product_reviews
UNION ALL
SELECT CAST(ticket_id AS VARCHAR), subject, description, 'ticket', category, CAST(NULL AS INT), ticket_date::DATE, customer_id
FROM support_tickets;

CREATE OR REPLACE CORTEX SEARCH SERVICE customer_feedback_search
  TEXT INDEXES title, doc_id
  VECTOR INDEXES content (model = 'snowflake-arctic-embed-l-v2.0')
  ATTRIBUTES source_type, category, rating, date_field, customer_id
  WAREHOUSE = hol_wh TARGET_LAG = '1 hour'
AS (SELECT doc_id, title, content, source_type, category, rating, date_field, customer_id FROM customer_feedback);

USE SCHEMA semantic;

CREATE OR REPLACE SEMANTIC VIEW business_analytics_semantic
TABLES (
    orders AS dash_automated_intelligence_db.raw.orders PRIMARY KEY (order_id)
        WITH SYNONYMS = ('sales', 'transactions', 'purchases') COMMENT = 'Customer orders with amounts and status',
    customers AS dash_automated_intelligence_db.raw.customers PRIMARY KEY (customer_id)
        WITH SYNONYMS = ('buyers', 'clients', 'users') COMMENT = 'Customer master data with segments',
    items AS dash_automated_intelligence_db.raw.order_items PRIMARY KEY (order_item_id)
        WITH SYNONYMS = ('line_items', 'order_details') COMMENT = 'Individual items within each order'
)
RELATIONSHIPS (orders (customer_id) REFERENCES customers, items (order_id) REFERENCES orders)
FACTS (
    orders.total_amount AS total_amount WITH SYNONYMS = ('order_value', 'sale_amount', 'revenue') COMMENT = 'Total monetary value of the order',
    items.quantity AS quantity WITH SYNONYMS = ('qty', 'units') COMMENT = 'Number of units ordered',
    items.unit_price AS unit_price WITH SYNONYMS = ('price', 'cost') COMMENT = 'Price per unit',
    items.line_total AS line_total WITH SYNONYMS = ('item_total', 'line_amount') COMMENT = 'Total value of the line item'
)
DIMENSIONS (
    orders.order_status AS order_status WITH SYNONYMS = ('status', 'state') COMMENT = 'Current status of the order',
    orders.order_date AS order_date WITH SYNONYMS = ('date', 'purchase_date') COMMENT = 'Date when order was placed',
    customers.customer_segment AS customer_segment WITH SYNONYMS = ('segment', 'tier') COMMENT = 'Customer classification tier',
    customers.first_name AS first_name COMMENT = 'Customer first name',
    customers.last_name AS last_name COMMENT = 'Customer last name',
    customers.state AS state WITH SYNONYMS = ('region', 'location') COMMENT = 'US state where the customer is located',
    items.product_category AS product_category WITH SYNONYMS = ('category', 'product_type') COMMENT = 'Product category classification'
)
METRICS (
    orders.total_revenue AS SUM(total_amount) WITH SYNONYMS = ('revenue', 'sales') COMMENT = 'Sum of all order amounts',
    orders.order_count AS COUNT(DISTINCT orders.order_id) WITH SYNONYMS = ('number_of_orders') COMMENT = 'Count of unique orders',
    customers.customer_count AS COUNT(DISTINCT customers.customer_id) WITH SYNONYMS = ('number_of_customers') COMMENT = 'Count of unique customers',
    orders.average_order_value AS AVG(total_amount) WITH SYNONYMS = ('aov') COMMENT = 'Average monetary value per order',
    items.total_items_revenue AS SUM(line_total) WITH SYNONYMS = ('item_revenue') COMMENT = 'Sum of all line item totals'
)
COMMENT = 'Semantic layer for natural language business analytics queries'
AI_VERIFIED_QUERIES (

        VERIFIED_AT 1772645863 ONBOARDING_QUESTION TRUE VERIFIED_BY '(STEWARD = dash)'

    ),

        VERIFIED_AT 1772645863 ONBOARDING_QUESTION TRUE VERIFIED_BY '(STEWARD = dash)'

    )
);

================================================================================
TROUBLESHOOTING FAQ
================================================================================

Q: Setup SQL timed out during data load
A: Increase the session timeout before retrying:
     ALTER SESSION SET STATEMENT_TIMEOUT_IN_SECONDS = 3600;
   Then re-run only the block that failed. Blocks are idempotent (CREATE OR REPLACE / FORCE = TRUE).

Q: "Insufficient privileges" or "Object does not exist or not authorized"
A: Ensure you are running as ACCOUNTADMIN:
     SELECT CURRENT_ROLE();
   If not ACCOUNTADMIN, run: USE ROLE ACCOUNTADMIN;

Q: DMF results are empty after Step 1
A: SNOWFLAKE.LOCAL.DATA_QUALITY_MONITORING_RESULTS populates asynchronously
   (up to 15 min after TRIGGER_ON_CHANGES fires). Wait and re-query, or check
   the view directly:
     SELECT * FROM dash_automated_intelligence_db.raw.vw_dq_monitoring_results ORDER BY measurement_time DESC LIMIT 10;

Q: Dynamic Table stuck in REFRESHING or shows 0 rows
A: Check the refresh history for errors:
     SELECT * FROM TABLE(INFORMATION_SCHEMA.DYNAMIC_TABLE_REFRESH_HISTORY())
     ORDER BY DATA_TIMESTAMP DESC LIMIT 10;
   Upstream DTs must finish first (Tier 1 before Tier 2 before Tier 3).

Q: Cortex Search returns no results or stale data
A: Cortex Search indexes build asynchronously after CREATE and may take a few
   minutes. Force a refresh:
     ALTER CORTEX SEARCH SERVICE dash_automated_intelligence_db.raw.customer_feedback_search REFRESH;

Q: Agent not appearing in CoWork (AI & ML > Snowflake CoWork)
A: On fresh accounts, agents auto-appear. On accounts with an existing Snowflake
   Intelligence object, register manually:
     ALTER SNOWFLAKE INTELLIGENCE SNOWFLAKE_INTELLIGENCE_OBJECT_DEFAULT
       ADD AGENT DASH_AUTOMATED_INTELLIGENCE_DB.SEMANTIC.BUSINESS_INSIGHTS_AGENT;

Q: CoCo prompts produce SQL errors
A: CoCo may need a retry for newer APIs. Let it self-correct.
   If it persists, copy the SQL from this file and run directly.
